# podGopher

**Actual status is work in progress**

**podGopher** — a lightweight **Podcast Content Management System (CMS)** written in **Go**.  
It provides a backend and tools to manage and publish podcast data — such as shows, episodes, metadata and feeds — in a structured, extendable way.

This project aims to make it easy to host, organize, and serve podcast content for personal or small-team use.

## 🚀 Features

✔ Built in Go for performance and portability

✔ Management of multiple shows

✔ Podcast management API

✔ Structured storage of podcast metadata

✔ RSS/Atom feed generation for podcast clients

✔ Docker support for containerized deployment
